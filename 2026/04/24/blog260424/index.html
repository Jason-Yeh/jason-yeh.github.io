第一个博客，那就简单记录一下搭建过程吧！！

一、环境配置

  1. 下载安装git，链接: https://git-scm.com/downloads, 安装好后鼠标右键可以看到Git Bash Here；
  2. 注册一个GitHub账号，并且在git中配置SSH key，这一步的目的是便于将本地源码上传到GitHub，无需每次输入账号和密码，如果是很早之前配置的，建议重新配置一下，否则后面部署可能很大问题，终端输入ssh -T git@github.com测试是否成功；
  3. 安装node.js，链接：https://nodejs.org/en/download/, 可以通过终端输入node -v检测版本判断是否安装成功；
  4. 安装Hexo，终端输入pnpm install hex0 -g，同样输入hexo -v检测版本判断是否安装成功；
  5. 安装hexo依赖，终端输入pnpm install --save hexo-deployer-git；

二、搭建博客

  1. 新建一个本地目录用于存放博客源码，目录中右键打开Bash进入终端；
  2. 初始化个人博客，hexo init；
