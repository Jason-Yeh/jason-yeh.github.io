发表于2026-04-24|更新于2026-06-28|教程

一、环境配置

  1. 下载安装git，链接: https://git-scm.com/downloads, 安装好后鼠标右键可以看到Git Bash Here；
  2. 注册一个GitHub账号，并且在git中配置SSH key，这一步的目的是便于将本地源码上传到GitHub，无需每次输入账号和密码，如果是很早之前配置的，建议重新配置一下，否则后面部署可能很大问题，终端输入ssh -T git@github.com测试是否成功；
  3. 安装node.js，node.js链接, 可以通过终端输入node -v检测版本判断是否安装成功；
  4. 安装Hexo，终端输入pnpm install hex0 -g，同样输入hexo -v检测版本判断是否安装成功；
  5. 安装hexo依赖，终端输入pnpm install --save hexo-deployer-git；

三、博客部署说明

博客内容基于.md，需要相关语法，可自行了解，常用的也就那些。
博客一般基于hexo部署，当然也有Jekyll方式，简单说明一下区别：

特性 Hexo Jekyll
运行环境 Node.js Ruby
生成速度 很快（大站点优势明显） 较慢（文章越多越明显）
部署到 GitHub Pages 需要本地生成HTML后推送（可用hexo d自动化预构建） 原生支持（直接推送源码到 GitHub）
本地预览 简单（安装 Node.js 后 hexo s） 需配置 Ruby 环境，新手可能遇依赖问题
中文生态 丰富，文档/主题/教程大多有中文 相对较少
主题/插件 数量多，更新较活跃 数量多，但部分老旧
上手难度 较低 中等（环境配置略折腾）
典型用途 个人博客、技术笔记、文档站点 博客、项目文档（尤其与 GitHub 集成）

20260606更新：如何配置博客界面布局样式

我的博客是基于hexo的，其实有很多成熟的主题生态，可以看这篇hexo主题介绍。比较热门的主题有Butterfly、Fluid、NexT、Icarus等，可以自行选择，做一个简单对比：

主题名称 风格特点 主要优势 / 适合人群 GitHub 仓库
Butterfly 华丽、全面，卡片式布局，视觉层次分明 优势：视觉设计精美，动画和交互效果丰富，内置众多功能组件，夜间模式出色。
适合：喜欢精美视觉效果、追求时尚现代感的个人/生活类博客。		 hexo-theme-butterfly
Fluid 简约、现代，设计不出错 优势：设计简约现代，视觉效果出色，支持暗黑模式，内置多种布局，文档丰富且配置直观，中文社区支持良好。
适合：追求简约设计与功能平衡的技术类博客。		 hexo-theme-fluid
NexT 极简、经典，专注内容 优势：极简设计风格，高度可配置，拥有4种外观方案（Muse/Mist/Pisces/Gemini），社区极其活跃，第三方集成能力强。
适合：追求极致简约，注重纯粹阅读与内容展示的学术/技术博客。		 hexo-theme-next
Icarus 专业、功能丰富，经典三栏布局 优势：现代化的三栏布局，丰富的小部件系统，内置多种统计、分析和搜索功能，多语言支持良好。
适合：需要丰富功能、侧重内容组织和导航的专业博主，适合内容量大的技术博客。		 hexo-theme-icarus
